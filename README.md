# 🚀 Projetos Inclusos neste Repositório

### 1. 🔍 Analisador de Segurança de Código Fonte (Desmistificando Buffer Overflow em C)
* *Arquivo principal:* teste.c
* *O que faz:* Um estudo prático sobre segurança em aplicações legadas. O script demonstra como funções inseguras em C abrem brechas para ataques de estouro de buffer (Buffer Overflow) e como corrigi-las utilizando alternativas seguras como fgets().
* *Conceitos Demonstrados:*
  * Identificação de falhas de gerenciamento de memória.
  * OWASP Top 10 (A03:2021-Injection / Memory Flaws).
  * Práticas de Code Review de Segurança.

### 2. ⚡ Scanner de Portas de Rede Automatizado (Network Port Scanner)
* *Arquivo principal:* teste1.py
* *O que faz:* Um script em Python leve e eficiente para realizar varreduras de segurança em redes locais. Ele analisa um endereço IP alvo para identificar quais portas de comunicação comuns (como 21, 22, 80, 443) estão abertas e expostas a possíveis ameaças.
* *Conceitos Demonstrados:*
  * Protocolos de Rede (TCP/IP, Handshake de 3 vias).
  * Reconhecimento Ativo (Footprinting).
  * Automação de tarefas defensivas/ofensivas com Python.

## 🛠️ Tecnologias, Ferramentas e Linguagens Utilizadas

* *Linguagens:* C (Desenvolvimento Seguro e Análise de Falhas) e Python (Automação de Scripts).
* *Ambiente de Desenvolvimento:* VS Code configurado em ambiente isolado de testes.
* *Metodologia:* Análise estática de código (SAST manual) e mapeamento de superfície de ataque.
