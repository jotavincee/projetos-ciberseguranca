### 📂 Ferramentas e Laboratórios de Segurança
Além do projeto principal, este repositório reúne scripts práticos focados em análise, redes, criptografia e defesa cibernética:

* *analisador_pcap.py*: Ferramenta de análise forense de rede que decodifica cabeçalhos IP em bytes de baixo nível (struct), extraindo TTL, IPs de origem/destino e identificando protocolos como TCP e UDP.
* *analisador_logs.py*: Script para leitura, triagem e detecção de anomalias em arquivos de log do sistema.
* *api_security_gateway.py*: Gateway de segurança para controle, validação e proteção de requisições em APIs.
* *buffer_overflow.c*: Estudo prático em C demonstrando vulnerabilidades de estouro de buffer e gerenciamento de memória.
* *gerenciador_segredos.py*: Utilitário com criptografia aplicada para armazenamento e manipulação segura de credenciais.
* *port_scanner.py*: Scanner de portas em Python para mapeamento de rede e auditoria de serviços expostos.
* *simulador_honeypot.py*: Ambiente simulado (honeypot) para atrair, registrar e analisar tentativas de intrusão.
* *verificador_integridade.py*: Monitor de integridade de arquivos (FIM) para detectar alterações não autorizadas.
